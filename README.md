Project Monitoring

## Описание

Монорепозитиорий

fullstack приложение для мониторинга проектов.

## Технологии

Frontend:

1.  React;
2.  TypeScript;
3.  React Router;
4.  Axios;
5.  Tailwind;

Backend:

1.  Node.js;
2.  Express;
3.  Prisma ORM;
4.  PostgreSQL;

Архитектура:
Frontend:
app - ядро проекта (main.ts)
pages - страницы
entities - бизнес-сущности
features - бизнес-логика
shared - общее, переиспользуемое
widgets - крупные ui-блоки

Безопасность:

1.  JWT-аутентификация;
2.  Валидация данных через Zod;

## Реализовано:

Аутентификация:

1.  Авторизация по логину и паролю;
2.  JWT-токен для пользователя (хранится в localStorage('dahilace-token'));
3.  Получение ткущего пользователя через auth/me;

Роли пользователей:
Manager(Руководитель):

1.  Список задач;
2.  Назначение ответственного;
3.  Редактирование всех полей задачи;
4.  Просмотр задач своих сотрудников;

Worker(Ответственный):

1.  Просмотр задач где он:
    Ответственный (может изменять только статус задачи) или создатель;

Работа с задачами:

1.  Создание задачи;
2.  Редактирование задачи;
3.  Просмотр списка задач;
4.  Сортировка задач на сервере (по умолчанию фильтрация на сервере с приоритетом по дате обновления, потом по дате создания);
5.  Фильтрация задач на клиенте;

Данные задачи:

1.  Заголовок и описание;
2.  Статус и приоритет;
3.  Дата создания и дата завершения;
4.  Создатель и ответственный;

## Установка

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/dahilace/react-project-monitoring
   ```
2. Установить пакеты:
   cd apps/backend
   ````bash
   npm i
   ---
   cd apps/frontend
   ```bash
   npm i
   ````
3. Настроить .env
4. Инициализировать prisma seed
   cd apps/backend/prisma
   ```bash
   npx prisma db seed
   ```
5. Запуск backend
   ```bash
   npm run dev
   ```
6. Запуск frontend
   ```bash
   npm run dev
   ```
